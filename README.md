# Science Sim Lab | 理科シミュレーターラボ

index.htmlが教材一覧です。31教材を収録しています。力学6教材は「力のはたらき LAB」の中から選べます。

## 設置

完成版ZIPを展開し、中のファイル・フォルダをGitHub Pagesのリポジトリ直下へ追加・上書きしてください。index.htmlとvisual-assetsを同じ階層に置きます。既存フォルダを削除せず、同名のファイルを上書きします。リポジトリ名の付いたURLでもリンクが動くよう、ホームのリンク先は相対パスindex.htmlです。

3D教材には外部ライブラリ・テクスチャの読み込みやWebGLが必要なものがあります。JSONの読み込みを使う教材はGitHub Pages等のHTTPサーバーから開いてください。

## 2026-09-14 状態変化と加熱曲線

温度の表示はセルシウス温度（℃）、横軸・操作・数値表示は加熱時間（秒）に変更しました。ジュールの表示・入力はありません。一定の強さで加熱した記録を10倍速で再生します。10秒前／10秒後の操作は加熱記録を見る時刻の移動で、冷却ではありません。加熱の強さは試料に伝わる正味1000 Wで固定し、内部の熱量モデルから温度と各状態の割合を計算します。0 ℃と100 ℃の停滞は保持しています。

PC低画面1366×600とタブレット768×1024でページのはみ出しがないことを確認。20秒の融解中は0 ℃、100秒から120秒へ加熱が進む間の沸騰中は100 ℃となることを実ブラウザで確認しました。

## 2026-09-14 状態変化の3D表示・横軸改良

状態変化と加熱曲線を、回転できる3D容器とグラフを並べる画面に再設計しました。氷の塊、液面、沸騰時の泡、圧力一定を表す可動ふたを表示します。水蒸気は白い煙にせず、透明な領域と質量の数値で示します。容器の高さや気体の体積は模式的な表現で、実寸・実際の体積比ではありません。

グラフの横軸は分・秒。現在時刻を「1分52秒」の形で表示します。0〜2分、0〜6分、0〜11分の範囲を手動で選び、条件変更で自動拡縮しません。現在時刻が範囲外なら案内と「全体を見る」ボタンを表示します。

3Dの透視投影と面の奥行き処理をCanvasで描画するため、この教材にはWebGLや外部3Dライブラリは不要です。ドラッグと矢印キーで回転できます。PC1366×600・タブレット1024×768／768×1024のページ・各パネルではみ出しなしを確認しました。氷、融解中、水、沸騰中、水蒸気の量と温度は従来と同じ熱量モデルに対応します。ブラウザで融解、沸騰、終了時、視点回転、横軸の切替と範囲外案内を確認しました。
