# Science Sim Lab | 理科シミュレーターラボ

中学理科のインタラクティブ・シミュレーターを1か所に集めたポータルです。
`index.html` がホーム画面で、各カードからフォルダ内のシミュレーターが開きます。

## 公開方法 (GitHub Pages)

1. このフォルダの中身をそのままリポジトリに入れて push する
2. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして Save
3. 数分後 `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## 収録内容

- 物理 8 / 化学 1 / 地学 7 / 宇宙 3 (計19教材)
- `Power/` : 力のはたらき LAB (6テーマ)
- `cosmo/` : 太陽系3D・宇宙物理シミュレーター
